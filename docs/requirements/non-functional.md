# 非機能要件

[← 要件定義書に戻る](../requirements.md)

- **実行環境:** バックエンド（Spring Boot、`http://localhost:8080`）とフロントエンド（Vite dev server、`http://localhost:5173`）を起動し、PostgreSQL（`docker-compose.yml`）に接続して動作する。詳細な起動手順は[ルートのREADME](../../README.md)を参照。
- **対応ブラウザ:** Chrome / Edge / Firefox / Safari の最新版を対象とする。
- **パフォーマンス:** カード件数が数百件程度の個人利用を想定し、体感的な待ち時間が発生しない軽量さを保つ。
- **操作性:** リスト名は見出しの入力欄を直接編集して変更でき、キーボード操作（Enterで確定、Escで取消）にも対応する。カードの編集は詳細モーダルから行う。
- **堅牢性:** API呼び出しが失敗した場合の挙動は「障害時の挙動」を参照。

## セキュリティ

- 現状はローカル開発環境での利用を前提とし、認証・認可の仕組みは持たない。ネットワーク上に公開する場合は、別途認証の追加が必要（[制約・前提条件](roadmap.md)を参照）。
- フロントエンドはReactのJSXを介して値を描画しており、`dangerouslySetInnerHTML` 等でユーザー入力をHTMLとして解釈させる実装は行わない（意図しないタグ・スクリプトの埋め込みは無効化される）。
- バックエンドはSpring Data JPAのプレースホルダ付きクエリ（`Specification` / JPQLの暗黙のバインド変数）を用いており、SQLインジェクションに対する対策を個別実装する必要はない。

## アクセシビリティ

- 検索欄・優先度セレクト・カードのタイトル/優先度/期限日の各入力には `aria-label` を付与し、スクリーンリーダーでの識別性を確保している。
- 削除ボタン（リストの✕）には `aria-label`（例:「リスト「○○」を削除」）を付与している。
- カード移動はHTML5 Drag and Drop APIのみに依存しており、キーボード操作による代替手段（矢印キーでの移動など）は提供しない。
- 対応レベル: 本バージョンではWCAG等の達成基準への準拠は目標としない。

## 対応デバイス・画面幅

- PCでのマウス操作を前提としたレイアウトとする。リスト幅は260px固定で、ボード全体は横スクロールで対応する。
- メディアクエリによるレスポンシブ対応は行わない（`frontend/src/styles/global.css` にブレークポイントは存在しない）。
- スマートフォン・タブレットでの利用は対象外とする。特にカードの移動はHTML5 Drag and Drop APIに依存しており、タッチ操作では動作しない。
- 想定する最小画面幅は1024px程度とする。

## 障害時の挙動

- **初回読み込みの失敗:** カード一覧の取得に失敗した場合、ボード領域にエラー内容と「再試行」ボタンを表示する。
- **操作中の失敗:** カードの移動・並び替え・リストの追加/名称変更/削除が失敗した場合、ボードは表示済みの内容を保持したまま、画面上部にエラーバナー（閉じるボタンつき）を表示する。
- **エラー文言:** ネットワーク接続不可・4xx・5xxの原因ごとに、日本語の文言に変換して表示する（`frontend/src/api/client.ts` の `ApiError`）。
- **JavaScriptが無効な環境:** React製のSPAのため、ボード領域は空のまま表示される（noscript対応は行わない）。
