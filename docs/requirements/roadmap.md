## 制約・前提条件

**ローカル開発環境のみを想定。** データはPostgreSQL（`docker-compose.yml`）に保存されるため、同じDBに接続する限り端末やブラウザを問わず同じデータを参照できる。ただし、現状は本番環境へのデプロイ・公開運用を行っていないため、社外や別端末からのアクセスにはバックエンドのデプロイが別途必要。

**認証なし。** ログイン機能を持たないため、バックエンドにアクセスできる利用者は誰でも全カードを閲覧・編集・削除できる。ネットワーク上に公開する場合は認証の追加を検討する。

## 今後の拡張候補

優先度の目安つきで、想定される拡張を列挙する。実装するかどうかは都度判断する。

| 優先度 | 候補機能 | 状態 |
| --- | --- | --- |
| 高 | カードの説明欄・ラベル（色分け） | 未着手 |
| 高 | 完了したタスクのアーカイブ表示 | 未着手 |
| 中 | 複数ボードの作成・切り替え | 未着手 |
| 中 | カードの検索・絞り込み | 実装済み（キーワード・優先度・リストIDによる絞り込み） |
| 中 | リストの並び替え（position変更） | 未着手（リストの追加は常に末尾） |
| 低 | マルチデバイス同期（バックエンドのデプロイ・公開運用） | 未着手。現状はローカル開発環境でのみ動作を確認しており、複数端末間で同期して使うには別途デプロイ・運用が必要 |
| 低 | ユーザー認証、複数人での共有・共同編集 | 未着手 |

データモデルは[データモデル](data-model.md)のER図、採用技術は[技術スタック](tech-stack.md)を参照。実装状況の詳細は[backend/README.md](../../backend/README.md)・[frontend/README.md](../../frontend/README.md)を参照。
